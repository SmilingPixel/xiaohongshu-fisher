# 第一期功能设计：阅读与发现

## 用户目标

用户在 VS Code 内查看小红书推荐内容、发现热门主题、按关键词找笔记，并在独立阅读页查看笔记。浏览体验以扫描标题和摘要、快速打开、回到列表继续阅读为核心。

## 信息架构

Activity Bar 增加“小红书”容器，包含：

| 视图 | 内容 | 主要操作 |
| --- | --- | --- |
| 推荐 | 登录用户首页信息流 | 刷新、加载更多、打开笔记 |
| 发现 | 平台公开的发现/热门入口；具体栏目以网页可读数据为准 | 刷新、打开笔记 |
| 搜索 | 当前关键词的笔记结果 | 输入关键词、重搜、加载更多、打开笔记 |

侧栏 TreeItem 展示笔记标题、作者、互动量（可获取时）、内容类型标记和时间（可获取时）。摘要或媒体缩略信息作为描述，不展示大型图片，避免挤占侧栏。列表按平台返回顺序显示，不在客户端推断推荐权重。

## 核心流程

### 首次使用

1. 用户打开“小红书”视图。
2. 插件检查独立浏览器会话状态；无会话时给出“登录小红书”和“在浏览器打开”操作。
3. 用户在可见的官方页面中自行登录，返回 VS Code 后刷新视图。
4. 会话过期或页面出现验证时停止读取并提示用户回浏览器处理，不尝试自动处理验证码。

### 阅读推荐/发现

1. 进入视图时按需加载首屏，不在扩展激活时自动抓取所有内容。
2. 每个 feed 有独立刷新和加载更多命令；加载期间只阻止同一 feed 的重复请求。
3. 列表按 `noteId` 去重；新页失败时保留已有结果并提示失败原因。
4. 选择列表项后打开 WebView 阅读页；列表焦点和滚动位置保留。

### 搜索

1. 用户触发“搜索小红书笔记”，输入关键词。
2. 空字符串不发请求；新搜索取消旧搜索并清空旧游标。
3. 搜索结果包含标题/正文摘要、作者和可用媒体信息；无结果时显示空状态。
4. 搜索视图记录当前关键词，允许刷新和加载更多。

### 笔记阅读

阅读页展示标题、作者、发布时间（若可获取）、正文、图片序列、视频封面/外链、话题和可访问的公开元数据。用户可在插件 WebView 中调整字体和媒体显示密度，并可通过命令在系统浏览器打开原笔记。不得自动播放视频。

## 命令草案

| 命令 ID | 用途 |
| --- | --- |
| `xiaohongshu-fisher.refreshHomeFeed` | 刷新推荐 |
| `xiaohongshu-fisher.refreshExploreFeed` | 刷新发现 |
| `xiaohongshu-fisher.searchNotes` | 搜索笔记 |
| `xiaohongshu-fisher.loadMore` | 加载当前列表下一页 |
| `xiaohongshu-fisher.openNote` | 打开笔记阅读页 |
| `xiaohongshu-fisher.openInBrowser` | 在系统浏览器打开原链接 |
| `xiaohongshu-fisher.openLogin` | 打开独立的官方登录窗口 |
| `xiaohongshu-fisher.clearSession` | 关闭并清除插件专属会话 |

命令应通过 `package.json` 的 `contributes.commands` 声明，并可从 TreeView 标题栏或空状态入口触发。刷新、登录、搜索等动作不在树项右键菜单中重复堆叠。

## 数据模型草案

```ts
interface FeedItem {
  id: string;
  title: string;
  excerpt?: string;
  author?: { id?: string; name: string; avatarUrl?: string };
  coverUrl?: string;
  mediaType?: "image" | "video" | "mixed";
  noteUrl: string;
  publishedAt?: string;
  stats?: { likes?: number; comments?: number; collects?: number };
}

interface NoteDetail extends FeedItem {
  body: string;
  images: Array<{ url: string; width?: number; height?: number; alt?: string }>;
  video?: { coverUrl?: string; url?: string };
  topics?: string[];
}
```

ID 必须从平台实体 ID 规范化产生；不能用标题或列表下标作为身份。可选字段缺失不应导致整条笔记丢失。

## 状态与空状态

- 未登录：登录官方页面、打开原网页。
- 加载中：视图标题显示进度，列表保留已有项目。
- 空结果：显示查询词/栏目相关的空状态和刷新入口。
- 登录失效：提示用户在官方浏览器页完成登录后重试。
- 页面结构改变：报告“暂时无法解析此页面”，保留在浏览器打开链接的选项。
- 环境不支持浏览器自动化：明确说明并提供外部浏览器打开方式。

## 首期验收标准

1. 未登录状态下不会自动发起内容请求；用户能主动打开官方登录页并建立可复用的本地会话。
2. 能加载至少一个推荐/发现 feed、执行关键词搜索、翻页并打开笔记详情；若平台当前页面不支持某栏目，则隐藏该栏目或给出明确不可用状态。
3. 列表分页不会重复插入同一笔记，刷新失败不会清空此前已加载结果。
4. 详情页能展示文本和图片，并对不支持的媒体给出原链接；不自动播放媒体。
5. Cookie、签名、个人会话信息不会写入日志、工作区设置或 WebView 消息。
6. 失效/风控/解析变化均停止自动重试，不调用发布、评论或社交互动接口。

## 本期明确不做

发帖、编辑/删除笔记、评论或回复、点赞/收藏/关注、私信、批量下载媒体、离线全文库、跨账号同步、云端代理、AI 内容处理和“伪装办公”模式。
